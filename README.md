# Skills de Joan Medina

Skills para Claude pensadas para el trabajo de oficina, no solo para programar. Son las que publico en abierto en [joanmedina.es/recursos](https://joanmedina.es/recursos/).

## Instalar

Todas:

```bash
npx skills@latest add joanmedina/skills
```

Una sola:

```bash
npx skills@latest add joanmedina/skills --skill sparring-ceo
```

Si prefieres no usar la terminal, cada skill tiene en la web su archivo ZIP y unas instrucciones paso a paso.

## Qué hay

| Skill | Para quién | Qué hace |
|---|---|---|
| [`sparring-ceo`](sparring-ceo/SKILL.md) | Dirección y gerencia | Contrasta una decisión antes de tomarla: reconstruye tu argumento, busca el supuesto que más pesa y propone la prueba más barata para salir de dudas. |
| [`control-entrega`](control-entrega/SKILL.md) | Operaciones y gestión de proyectos | Revisa un trabajo antes de que llegue a un cliente, en seis bloques de comprobación, y termina con un veredicto claro. |
| [`diagnostico-crecimiento`](diagnostico-crecimiento/SKILL.md) | Dirección y gerencia | Busca el cuello de botella que frena el crecimiento de un negocio y ordena qué hacer primero. |
| [`estado-proyecto`](estado-proyecto/SKILL.md) | Operaciones y gestión de proyectos | Deja por escrito cómo va un proyecto: qué está hecho, qué está comprobado, qué falta y qué decisiones esperan. |
